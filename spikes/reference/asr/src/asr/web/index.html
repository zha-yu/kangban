01 / 声纹档案

让康伴认识你的声音

在安静的环境中，自然说话 6 秒。
例如介绍自己，或说说今天的计划。

更改将在下次唤醒 / 录入时生效。点此下拉会请求麦克风权限以列出设备。

正在读取声纹档案…

阈值越高，验证越严格。建议用本人和其他人的录音测试后调整。

越低越敏感（容易触发人声），越高越严格（只响应大声说话）。"说话没反应"就把它调低。

开启后无需录入声纹即可直接测试 ASR，适合开发调试阶段。
