## 4. 已验证为正确的设计（防误报）

1. **companion.py 未提交改动无风险**：仅补 `llm_first_token` 打点，`llm_first_token` 在 DB 白名单内可正常落库；预算复位/高危预拦截/重试不计预算均完好。
2. **ack 四步校验核心正确**：epoch 对会话当前值校验、仅 played 推进水位、前缀拼接等价 handoff 规则 1、重复/乱序被拒、canceled 跳过单调校验符合契约。
3. **投影防回退**（`_apply_delivered` 只接受不更短版本）实现正确——问题只在无人调用。
4. **前端 epoch/兜底双路径幂等**：onResponseSettled 三重守卫无重复上报、epoch 只增不误杀、cancelTail 覆盖全部 5 个状态变更点。
5. **VAD 加载失败降级链路完整**（init_error/脚本错误/30s 超时三路 → 服务端 webrtcvad 接管 + diag）；运行期死亡才是盲区（P1-6）。
6. **CAS Lua 原子性 / read_turns 会话生命周期与越权防护 / seq 排序防同事务时间戳错序 / E20 主链路权限审计与无 N+1 批量查询 / admin 行不显示改绑按钮语义正确**——均验证无误。
7. **AdminUsersPage role!==admin 按钮可见性与建档剥离 elder_ids 前后端口径一致**，不存在 admin 自改绑路径。
