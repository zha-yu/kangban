## 2. 口径要点

- 展示字段：长者 / recorded_at / source 四值 / operator（staff_* 时）/ 5 字段 / severity + rule_version / version / review_status。
- 纠错至少改一项才可提交；新版本 severity 由阈值常量重算（复用 health-api 分级逻辑，抽公共函数）。
- corrected 记录展示「已纠错 → 指向新版本」链接关系；confirmed/corrected 退出队列。
- 黄档护工复核、红档医生复核（reviewed_by 语义）——医生端只看全部 pending，不按档限制操作（Mock 简化，留痕）。

## 3. 验收清单

```
[ ] 医生登录 → 侧栏「复核队列」进真实页；红档置顶、时间倒序
[ ] 确认无误 → confirmed + 复核人留痕，退出队列
[ ] 纠错 → 新版本（version+1、severity 重算）+ 原记录 corrected + superseded_by 指向；原值可查（版本链）
[ ] 130 误输 180 纠错链在 Mock 数据中可见；纠错至少改一项校验
[ ] Mock 全虚构；tsc/build 通过；零硬编码 hex；零后端文件改动
```
