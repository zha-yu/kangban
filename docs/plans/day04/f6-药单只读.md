## 2. 口径要点

- 展示字段：drug_name / dose / schedule_cron（转文案） / start_date / end_date / version / status(active/stopped) / created_by 医生名；version 与快照规则（AC-27：历史提醒保留旧快照）在提示文案说明，不做交互。
- status 两态：active「用药中」success 徽标、stopped「已停用」neutral 徽标。
- 全部教学演示数据虚构，页面标注「教学演示数据，不构成真实处方」（PRD §4.5 原口径）。
