## 1. 目标

在照护台（护工页面）闭环「长者注册 → 分配床位 → 分配设备 → pad 设备页录入声纹」全流程。pad 端声纹录入（VoiceprintGate → VoiceprintEnroll）已有完整实现，零改动。

## 2. 裁决（主理人 2026-11-06）

1. **权限放开**：契约 E5（长者建档）/ E9（设备绑定）从仅 admin 放开到 care_worker；改停（E8）/ 解绑（E10）仍仅 admin。已登记契约 v1.8。
2. **设备来源**：新增设备建档接口 E16（一次性明文 device_secret，pad 用 device_id + secret 登录），不用预置脚本。

## 3. 实现

### 后端（契约 v1.8 四端点）

| 端点 | 落点 | 说明 |
| --- | --- | --- |
| E16 `POST /api/devices` | `app/services/device_service.py` + `app/api/devices.py` | 建档生成 `secrets.token_urlsafe(32)`，库内只落 SHA-256；404 房间不存在 |
| E17 `GET /api/devices` | 同上 | JOIN rooms 取 room_no，含未绑定设备 |
| E18 `GET /api/rooms` | `app/services/elder_service.py` + 新建 `app/api/rooms.py` | 房间 + 全量床位（含空床），员工全量可读，家属/设备 403 |
| E19 `POST /api/elders/{elder_id}/bed` | `app/api/elders.py` + `app/services/elder_service.py` | 换床语义（先腾旧床）；床位被占 409；零迁移 |

门禁：新增 `_require_staff_write`（admin + care_worker），拒绝先审计再抛，与 `_require_admin` 同节奏。

### 前端 console

- `frontend/src/console/api.ts`：新增 `apiPost` / `apiGetWithStatus`。
- `frontend/src/console/elders-api.ts`：`createElder / fetchRooms / assignBed / fetchDevices / createDevice / bindDevice`。
- `frontend/src/console/pages/EldersPage.tsx`：页头「注册长者」按钮 → 四步向导（建档 → 选房选床 → 选设备/新建设备展示一次性密钥 → 完成引导去 pad 登录录声纹）；详情卡对无床位长者提供「分配床位/设备」入口。
- `frontend/src/console/index.css`：补 `.wiz-*` 样式。
