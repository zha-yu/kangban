# 计划 · 收音与识别优化（adhoc，2026-11-06）

## 背景

联调实测发现两个问题（主理人 2026-11-06 口径确认）：

1. **对话 ASR 准确率**：识别结果偶有同音字/断句错误；FunASR 协议层拿不到 confidence（`asr.py` 已注明恒 None），识别引擎本体在教师共享服务内，本仓不可调参。
2. **收音范围过宽**：他人语音会被收进对话链路（触发切段与识别）；声纹录入页也无环境自检，他人声音可能污染样本。

## 边界裁决（本轮已确认）

- **不做**说话人分离/「只听绑定长者」：不在 PRD 范围，声纹仅作身份归因辅助；他人声音最多偶尔触发一轮对话，属可接受降级。
- **不做**录入页念读文本校验（方案乙）：属新增能力，需改 C4 契约，本轮不做。
- AEC/NS/AGC 三件套已按 adhoc §2.3 全开，不动 getUserMedia 约束。

## 启发式常量（A5，代码顶部集中放）

- `AMBIENT_CHECK_MS = 3000`：录前环境采样时长。
- `AMBIENT_NOISY_AVG = 0.03`：3s 均值 RMS（int16 归一化）超过即判「偏吵」，**只提示不阻断**（长者位置不可控，误报代价低）。
- 录音电平条映射 `min(rms × 400, 100)%`，仅供可视化自查。

## FunASR 热词口径（A3）

- 协议：FunASR runtime 握手支持 `hotwords` 字段（`"词 权重"` 空格分隔，权重 1~100）。教师共享镜像的模型是否启用 seaco 解码器**未确认**——字段发出去不生效也无害，故做成可配置 + 默认空。
- 热词内容（建议初始集）：`小伴 20`、`小满 20`、`越剧 20`、`京剧 20`。经 `.env` 注入，不硬编码。
- 新配置默认空回落原行为（项目约定）。
