# 声纹互测录音操作指南（现场人员版）

**给谁看**：参与今天声纹互测的每一位录制者。全程约 **10 分钟/人**，不需要懂代码，照下面做即可。

---

## 一、我们要录什么、为什么

系统靠「声纹」识别说话的人（Cosine 相似度 ≥ 0.55 判定同一人）。今天要采集**真人录音样本**，用来：

1. 统计「同一个人的不同录音」和「不同人之间」的相似度分布；
2. 验证 0.55 这个判定阈值是否合理（会不会认错人、会不会认不出人）；
3. 生成评测报告存档。

**隐私说明**：录音只存在你电脑的 `spikes\voiceprint\samples\` 文件夹里（已配置**不入 Git 仓库**），评测完成后**随时可以删除**；本次只采集项目成员/在场志愿者的声音，**不涉及任何真实长者**。

---

## 二、开录前的 3 项检查

| # | 检查 | 说明 |
| --- | --- | --- |
| 1 | 找个安静的环境 | 关窗、关风扇，避免别人同时说话——背景噪音会拉低相似度 |
| 2 | 麦克风可用 | 脚本启动时会自动显示检测到的麦克风名称，录音时有实时音量条 |
| 3 | 知道自己的「人名代号」 | 拼音、全小写、**不含空格和下划线**（如 `zhangsan`），所有录音共用同一个代号 |

---

## 三、标准流程（推荐，电脑自带麦克风）

**第 1 步**：在项目根目录打开终端（PowerShell），运行：

```powershell
uv run --with sounddevice --with numpy python spikes\voiceprint\record_samples.py
```

**第 2 步**：按提示操作——

```
输入设备：麦克风阵列 …（自动检测）
人名（拼音/字母，如 zhangsan）：zhangsan
段数（回车默认 3）：          ← 直接回车，录 3 段
```

**第 3 步**：每段开始前有 **3 秒倒计时**，然后录 **6 秒**（脚本自动掐表）：

- 屏幕上会出现实时音量条 `[########] 3s/6s`；
- 如果显示 `（检测不到声音，检查麦克风）`，先说句话确认麦没哑。

**第 4 步**：每段录完自动保存，文件名自动编好：

```
spikes\voiceprint\samples\zhangsan_1.wav
spikes\voiceprint\samples\zhangsan_2.wav
spikes\voiceprint\samples\zhangsan_3.wav
```

**第 5 步**：录完一位会问 `继续录下一位？` ——下一个人回车继续，全员录完输入 `q` 退出。

---

## 四、录音要点（直接影响评测结果，务必遵守）

1. **每段之间停下来，重新说一遍**——不要一口气连读 18 秒被切成 3 段。连读会让「同人相似度」虚高，评测结论失真。
2. **正常说话**：正常音量、正常语速，随便聊两句、读一段新闻都行；不需要念固定文本。
3. **每段 ≥5 秒**（脚本固定录 6 秒，照做即可）。
4. **人名代号前后一致**：`zhangsan` 录 3 段都用 `zhangsan`，中途不要变成 `zhang san` 或 `zs`——脚本按代号分组判断「谁是谁」。
5. 至少 **3 段/人**；人有几个就要几个人都录（互测需要「不同人」的对比）。

---

## 五、备用方案：手机录音 / Windows 录音机

不方便用电脑麦克风？用手机或 Windows「录音机」录也行，但**默认格式不是 wav**，需要转换一次：

```powershell
uv run python spikes\voiceprint\record_samples.py convert <你的m4a或mp3文件路径> zhangsan
```

- 每转换一次自动生成一个 `zhangsan_N.wav`（序号自动累加）；
- 需要电脑装有 ffmpeg（没有的话提示 `winget install ffmpeg` 安装）；
- 转换会自动变成 16kHz 单声道，不用手动调格式。

> 注意：手机录音仍要遵守第四节的要点（分段重录、每段 ≥5 秒），并且要把文件先传到这台电脑上再 convert。

## 六、录完后的自查清单

- [ ] 参与者都录了，每人 ≥3 段
- [ ] 文件都在 `spikes\voiceprint\samples\` 下
- [ ] 文件名格式正确：`<人名>_<序号>.wav`，无空格无多余下划线
- [ ] 有一个人录的段数和文件序号连续（1、2、3，不缺号）

自查完告诉 dev-B，执行扫描：

```powershell
uv run python spikes\voiceprint\threshold_sweep.py
```

（扫描会自动调用声纹容器，输出 FAR/FRR 表和误识/拒识明细，数据底稿落 `eval\reports\voiceprint_sweep_raw.json`。）

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 音量条一直显示「检测不到声音」 | 检查系统麦克风开关与隐私授权（设置 → 隐私 → 麦克风）；换一个输入设备重跑脚本 |
| 报错 `没有检测到麦克风输入设备` | 外接麦克风没插好，或被其他程序独占；重插后重跑 |
| 录错了一段想重录 | 直接告诉 dev-B 文件名，删掉对应 wav 后用脚本重录该段（序号续上） |
| 手头录音是 wav 但采样率不是 16k | 不用管，扫描脚本和容器能处理，只有 16k 单声道最优 |
| 评测结束后想删除录音 | 整个 `samples\` 文件夹可以整删，不影响任何代码与仓库 |
