## 一、登录与声纹注册（开场 5 分钟，只需做一次）

### 1. pad 登录（每台设备一次）

1. 打开 pad 页面 → 登录页粘贴 **device_id**（设备主键 UUID）换证（免密钥，2026-11-11 起）。
2. device_id 从数据库取（两位长者的绑定设备各一个）：

```powershell
docker exec silvermate-postgres psql -U silvermate -d silvermate -c `
  "SELECT d.device_id, e.name AS elder, r.room_no FROM devices d JOIN elders e ON e.elder_id=d.elder_id LEFT JOIN beds b ON b.bed_id=e.bed_id LEFT JOIN rooms r ON r.room_id=b.room_id WHERE d.status='active';"
```

### 2. 声纹注册（每位演示者一次，3 段 × 现场录制）

1. 长者 A 本人在 pad 打开「声纹注册」（`VoiceprintEnroll` 页面）→ 按页面引导录 3 段（每段几秒即可）；
2. 提示注册成功后，状态查询：

```powershell
# 用设备 token 调（或直接看注册页显示的状态）
curl.exe -s http://127.0.0.1:8000/api/voiceprints/status -H "Authorization: Bearer <设备token>"
```

3. 长者 B 如参与第二幕，同样在其自己的设备上注册（**候选集=设备绑定长者本人 1v1，PRD v2.6**——B 不在 A 的设备上注册）。

## 二、三幕演示（每幕留证后再进下一幕）

### 幕 1 · 单人间设备锁定（FR-VPR-01 前半）

| 步骤 | 操作 |
| --- | --- |
| 1 | 设备 A 已绑定长者 A，页面在待唤醒/空闲态 |
| 2 | **长者 A 本人开口**（唤醒词「小伴」或按住说话），说「小伴，今天天气怎么样」 |
| 3 | 期望：**直接进入 A 的会话**，无任何「请问是谁」弹窗——身份由设备绑定直接确定（source=device） |

**留证①**：pad 页面截图（会话已进入 + 顶部长者 A 身份标识）。
**留证②**：后端日志/库中该轮 `source=device` 留痕（收口时统一提取）。

### 幕 2 · 声纹比对命中（FR-VPR-01 验收主干）

| 步骤 | 操作 |
| --- | --- |
| 1 | 设备 A 每会话**首轮**声纹校验（2026-11-06 裁决：单/双人间统一级联） |
| 2 | **长者 A 本人**（已注册声纹）再发起一次新会话首轮说话 |
| 3 | 期望：声纹相似度 **≥0.62** → 匹配命中，进入 A 的会话并加载 A 的个人记忆上下文 |

**留证①**：pad 页面截图（进入会话 + 记忆上下文标识）。
**留证②**：后端日志中的声纹匹配行（含 similarity 分数与 threshold=0.62）。

### 幕 3 · 声纹失败 → 主动确认（FR-VPR-02/03，H13④ 的关键兜底演示）

| 步骤 | 操作 |
| --- | --- |
| 1 | **第三者 C**（未在本设备注册声纹，可用 test2/其他同事）对设备 A 说话 |
| 2 | 期望：相似度 **<0.62** → 页面弹出大字确认卡（`identity_ask`）：「请问是哪位在说话？」 |
| 3 | C 点了「是我」（冒充长者 A）→ 期望：**confirm 的 elder_id ≠ 候选集** → 降级**通用模式**（不读 A 的记忆、不写健康记录、不确认用药，FR-VPR-03） |
| 4 | （可选加演）C 点「取消」→ 同样进通用模式 |

**留证①**：确认卡弹出的页面截图 + 通用模式提示截图。
**留证②**：后端日志 `identity_confirm elder_id 不匹配候选集，降级 generic` 行。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 幕 2 没触发声纹校验 | 首轮校验只在**每会话第一轮**触发——先点「结束会话」或刷新页面再重新开口 |
| 幕 3 C 说话被直接放行 | C 与 A 音色过近 + 阈值边缘：换一位音色差异更大的 C；这本身是有价值的观测数据，记录下来 |
| 唤醒词没反应 | 走降级链路「按住说话」即可，不影响声纹演示 |
| 页面报声纹服务不可用 | 检查 7003 容器（自检②）；声纹不可用时系统自动降级为「长者 ID + 主动确认」，也是合法分支 |
