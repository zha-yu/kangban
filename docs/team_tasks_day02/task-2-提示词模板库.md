## 目标

对应大纲 2.1 产出物。零代码依赖，上午就能交；后续每天都要复用，早交付有复利。

## 产出

`docs/prompts/` 下 ≥6 个模板文件 + 一个 `README.md` 索引。

> 仓库里已有 `docs/prompts/seed-prompt.md`（Day 1 的种子提示词）。它保留，作为索引里的第 0 条；本任务是在它基础上补成模板库 v1，不要重写它。

1. 需求澄清
2. 「先别写代码，先找问题」
3. 实现计划（先出方案、人批准再写）
4. 补测试
5. 调试报错
6. 写 commit

## 每个模板必须含

- **四要素结构**：Context（上下文）+ Task（任务）+ Constraints（约束）+ Expected Result（验收）
- **AGENTS §8 统一模板落位**：改哪些文件 → 验收命令 → 禁止触碰的文件 → 完成后报告 diff 摘要
- **固定前缀标注**：哪部分属于 system prompt / 人设 / 工具定义（这部分必须稳定才能命中 prompt cache，可变部分只能放在前缀之后）

## 禁止触碰

`app/` 下任何代码；`docs/` 三份基线正文。

## 验收

`docs/prompts/README.md` 能索引到 6 个模板；随便抽一个模板现场能直接贴进 AI 用。
