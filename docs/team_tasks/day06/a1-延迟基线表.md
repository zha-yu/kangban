## 2. 样本口径

- 21 个 trace；其中 **3 个 trace 仅 wakeup/connection/llm 三段**（无 asr/tts 行，见 §5 异常登记）、**2 个 trace 含 playback 代打行**（其一为双轮会话 9 行）。
- **有效单轮样本 = 16**（五段齐全且 llm 仅 1 次：剔除 3 异常 + 2 个 6-stage trace）。
- 端到端口径 e2e = `wakeup + connection + asr + llm_first_token + tts_first_packet` 五段之和（playback 是播放时长，不计入响应延迟）。
- 识别后响应口径 = `llm_first_token + tts_first_packet`（asr_final 之后到 TTS 出包，不含用户说话时长）。

## 3. 复算 SQL（可直接执行）

```sql
-- 每 stage P50/P95
SELECT stage, count(*) AS n,
  round(percentile_cont(0.5) WITHIN GROUP (ORDER BY duration_ms)) AS p50,
  round(percentile_cont(0.95) WITHIN GROUP (ORDER BY duration_ms)) AS p95,
  round(avg(duration_ms)) AS avg_ms
FROM metrics
WHERE stage IN ('wakeup','connection','asr','llm_first_token','tts_first_packet','playback')
GROUP BY stage ORDER BY stage;

-- 端到端（有效单轮样本）
WITH agg AS (
  SELECT trace_id,
    sum(duration_ms) FILTER (WHERE stage='wakeup') AS wakeup,
    sum(duration_ms) FILTER (WHERE stage='connection') AS conn,
    sum(duration_ms) FILTER (WHERE stage='asr') AS asr,
    sum(duration_ms) FILTER (WHERE stage='llm_first_token') AS llm,
    sum(duration_ms) FILTER (WHERE stage='tts_first_packet') AS tts,
    count(*) FILTER (WHERE stage='llm_first_token') AS llm_n,
    count(DISTINCT stage) AS n_stages
  FROM metrics GROUP BY trace_id
), valid AS (
  SELECT *, (wakeup+conn+asr+llm+tts) AS e2e, (llm+tts) AS respond_after_asr
  FROM agg WHERE n_stages = 5 AND llm_n = 1
)
SELECT count(*) AS valid_n,
  round(percentile_cont(0.5) WITHIN GROUP (ORDER BY e2e)) AS e2e_p50,
  round(percentile_cont(0.95) WITHIN GROUP (ORDER BY e2e)) AS e2e_p95,
  max(e2e)::int AS e2e_max, min(e2e)::int AS e2e_min,
  round(percentile_cont(0.5) WITHIN GROUP (ORDER BY respond_after_asr)) AS resp_p50,
  round(percentile_cont(0.95) WITHIN GROUP (ORDER BY respond_after_asr)) AS resp_p95,
  count(*) FILTER (WHERE e2e <= 1500) AS ac42_pass,
  count(*) FILTER (WHERE respond_after_asr <= 1500) AS resp_pass
FROM valid;
```

**AC-42 达标判定（≤1.5s，20 次中 ≥19 次）：**

| 口径 | 达标 / 样本 |
| --- | --- |
| e2e 全链路 | **0 / 16 —— 不达标** |
| 识别后响应（不含说话时长） | **0 / 16 —— 不达标** |

不达标主因（按贡献排序）：① ASR 段本地 FunASR 占 4.9s+（P50）；② LLM 非流式 1.5s+；③ TTS 非流式整段 1.5s+。三段口径本身都超预算（ASR 首包 300ms / LLM 首 token 800ms / TTS 首包 300ms），当前实现均为非流式兜底形态，属预期内如实结果。
